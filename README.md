# کهربا

**دفتر دیجیتال تعمیرکار وسایل برقی** — رایگان و کاملاً آفلاین.

بخاری، سماور، لباسشویی، کولر و هر وسیله‌ی برقی دیگری که به مغازه می‌آید، با یک پرونده‌ی کددار ثبت می‌شود:
مشتری ← دستگاه ← پرونده. همه‌ی اطلاعات فقط روی گوشی خود تعمیرکار می‌ماند و به هیچ سروری فرستاده نمی‌شود.

## امکانات نسخه‌ی فعلی

- **پرونده‌ها**: ثبت سریع (زیر ۳۰ ثانیه)، کد سالانه مثل `05-0142`، ۹ وضعیت، تاریخچه‌ی وضعیت، قطعات و اجرت، گارانتی، عکس قبل و بعد، یادداشت خصوصی
- **پیامک**: رسید پذیرش، اعلام هزینه و آماده‌ی تحویل با متن قابل تنظیم (از برنامه‌ی پیامک خود گوشی)
- **مشتری و دستگاه**: سابقه‌ی کامل، کد ثابت دستگاه مثل `BK-0037` با برچسب QR، عکس پلاک مشخصات
- **داشبورد**: کارهای در جریان، آماده‌ی تحویل، **هشدار وسایل جامانده**
- **بانک فنی**: کدهای خطا و راهنمای علامت‌محور، مراحل بررسی قابل تیک، یادداشت شخصی، آمار تجربه‌ی خود تعمیرکار
- **قطعات معادل**، **گزارش ماهانه**، **نرخ‌نامه**، دسته‌بندی قابل تنظیم
- **امضای مشتری** هنگام پذیرش و تحویل، روی رسید
- **پشتیبان‌گیری** در یک فایل و بازیابی، **همگام‌سازی با همکار** از Wi‑Fi محلی
- **قفل برنامه** با رمز، **اعلان نوبت‌ها** و یادآور پشتیبان (بدون اینترنت)
- تم روشن شامپاینی، تیره و مشکی (OLED)، واکنش‌گرا برای گوشی و تبلت

## اجرا

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

هر بار که جدول‌های `lib/data/database.dart` تغییر کرد، دستور `build_runner` را دوباره اجرا کنید.

## انتشار (مایکت)

۱. یک بار کلید امضا بسازید و جای امنی نگه دارید (گم شدنش یعنی دیگر نمی‌توانید به‌روزرسانی بدهید):

```bash
keytool -genkey -v -keystore kahroba-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias kahroba
```

۲. فایل `android/key.properties` (در git نیست):

```
storePassword=...
keyPassword=...
keyAlias=kahroba
storeFile=D:/keys/kahroba-release.jks
```

۳. پیش از هر نسخه `version` را در `pubspec.yaml` بالا ببرید (عدد بعد از `+` همیشه باید بزرگ‌تر شود) و `appVersion` را در `about_page.dart` هم‌اندازه کنید.

۴. ساخت:

```bash
flutter analyze
flutter test
flutter build apk --release --obfuscate --split-debug-info=build/symbols
```

خروجی: `build/app/outputs/flutter-apk/app-release.apk`. بدون `key.properties` ساخت release عمداً متوقف می‌شود.

## ساختار

```
lib/
├─ app.dart, main.dart
├─ core/        تم، ابزارها (تاریخ شمسی، تومان، ارقام)، سرویس‌ها (عکس، پیامک)، ویجت‌های مشترک
├─ data/        پایگاه داده (Drift)، وضعیت‌ها، مقادیر پیش‌فرض
└─ features/    dashboard, cases, customers, devices, knowledge_base, reports, settings, home
assets/kb/kb.json   محتوای بانک فنی
tools/              اسکریپت ساخت نسخه‌ی اولیه‌ی بانک فنی
```

## مشارکت در بانک فنی

محتوای بانک فنی در `assets/kb/kb.json` است. هر مورد یا کد خطاست (`"type": "code"`) یا علامت خرابی (`"type": "symptom"`).
فیلد `device` همان پیشوند دسته است (مثل `LS` برای لباسشویی، `BK` برای بخاری، `*` برای عمومی).
موارد بازبینی‌نشده `"verified": false` دارند. لطفاً از سرویس‌منوال‌ها کپی نکنید و با بیان خودتان بنویسید.
